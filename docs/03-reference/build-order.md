# Build order — superseded

The five-phase build order lived here until 2026-08-01. It is superseded by the agreed **[execution plan](execution-plan.md)** ([ADR-0016](../02-decisions/0016-execution-plan.md)): eleven stages plus a parallel mini track, five gates per stage, requirement docs before code.

For the archaeology: the five phases map onto the stages roughly as 1 → stages 1–2 · 2 → 3–4 · 3 → 5 · 4 → 6–7 · 5 → 8. The per-phase exit tests survive inside the corresponding stage exit tests.
